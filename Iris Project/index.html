WORKFLOW PIPELINE

How It Works

A seamless journey from botanical measurements to machine learning classification.

STEP 01 INPUT

Enter Measurements

Sepal & Petal Dimensions

Input four precise biometric measurements: sepal length, sepal width, petal length, and petal width in centimeters.

STEP 02 API REQUEST

FastAPI Processes Data

Pydantic Validation

FastAPI receives the JSON payload, validates the schema with Pydantic, and feeds the numerical array into the pipeline.

STEP 03 ML INFERENCE

SVC Model Predicts

Support Vector Machine

The trained Support Vector Classifier maps the measurements in higher-dimensional feature space to determine the hyperplane boundary.

STEP 04 OUTPUT

Species Result

Instant Botanical Profile

The client visualizes the final classification along with confidence percentage, botanical summary, and probability breakdown.
