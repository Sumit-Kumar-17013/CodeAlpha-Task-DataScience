# ✨ Project Overview

**Iris Vision** is an end-to-end Machine Learning project developed to classify Iris flowers into one of three species using four physical measurements.

The project goes beyond simply training a classifier.

It demonstrates a complete Machine Learning workflow:

```text
📊 Dataset
   ↓
🔍 Exploratory Data Analysis
   ↓
🧹 Data Understanding & Preprocessing
   ↓
📈 Visualization & Statistical Analysis
   ↓
🤖 Multiple ML Models
   ↓
🔄 Cross-Validation
   ↓
📊 Model Comparison
   ↓
🏆 Best Model Selection
   ↓
💾 Model Persistence
   ↓
⚡ FastAPI Backend
   ↓
🌐 Interactive Frontend
   ↓
🌸 Real-Time Prediction
