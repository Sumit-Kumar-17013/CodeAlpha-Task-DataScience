# 🚗 Project 02 — Car Price Prediction

## 🔎 Overview

The Car Price Prediction project focuses on predicting the selling price of a used car based on its characteristics.

This is a **regression problem** because the target variable is a continuous numerical value.

---

## 🎯 Objective

Build an end-to-end Machine Learning system capable of estimating the selling price of a used vehicle.

---

## 📊 Dataset Features

The project uses features including:

| Feature         | Description               |
| --------------- | ------------------------- |
| `Car_Name`      | Car/model name            |
| `Year`          | Manufacturing year        |
| `Selling_Price` | Target variable           |
| `Present_Price` | Present/ex-showroom price |
| `Driven_kms`    | Kilometres driven         |
| `Fuel_Type`     | Fuel category             |
| `Selling_type`  | Dealer / Individual       |
| `Transmission`  | Manual / Automatic        |
| `Owner`         | Previous owners           |

---

## 🧹 Data Preparation

The project included:

* Dataset inspection
* Data type analysis
* Missing-value checking
* Duplicate detection
* Duplicate removal
* Statistical analysis
* Distribution analysis
* Outlier investigation

The original dataset contained **301 records and 9 columns**.

After duplicate removal, the working dataset contained **299 records**.

---

## 🔍 Exploratory Data Analysis

I performed several visual analyses including:

### 📊 Distribution Analysis

Studied the distributions of numerical variables.

### 📦 Boxplots

Used to identify potential outliers.

### 🚘 Present Price vs Selling Price

Used to investigate the relationship between current price and selling price.

### 📅 Car Age / Year Analysis

Used to understand how vehicle age relates to resale price.

### 🛣️ Driven KMs Analysis

Studied the relationship between vehicle usage and selling price.

### ⛽ Fuel Type Analysis

Compared selling prices across fuel categories.

### ⚙️ Transmission Analysis

Compared prices for different transmission types.

### 🔥 Correlation Heatmap

Used to investigate relationships between numerical variables.

---

# 🛠️ Feature Engineering

Two important features were created.

### 🚘 Car Age

```python
Car_Age = Latest_Year - Year
```

This provides a more intuitive representation of vehicle age.

### 🛣️ Kilometres Per Year

```python
Kms_Per_Year = Driven_kms / (Car_Age + 1)
```

This represents approximate yearly usage.

---

# 📉 Skewness Analysis

Numerical variables were analyzed for skewness.

Log transformation was investigated using:

```python
np.log1p()
```

The analysis showed that `Present_Price` benefited from transformation.

The transformation was incorporated into the Machine Learning preprocessing pipeline.

---

# ⚙️ Preprocessing Pipeline

A `ColumnTransformer` was used to organize preprocessing.

The project included:

* `StandardScaler`
* `OneHotEncoder`
* `OrdinalEncoder`
* `FunctionTransformer`
* `Pipeline`
* `ColumnTransformer`

This created a reusable preprocessing workflow.

---

# 🤖 Models Compared

The project experimented with multiple regression algorithms:

```text
Linear Regression
Ridge Regression
Lasso Regression
Decision Tree Regressor
Random Forest Regressor
Gradient Boosting Regressor
Support Vector Regression
XGBoost Regressor
```

---

# 📏 Evaluation Metrics

The models were evaluated using:

* R² Score
* MAE
* MSE
* RMSE
* 5-Fold Cross-Validation

The project used **Cross-Validation Mean R²** as the primary model-comparison criterion.

---

# 🔧 Hyperparameter Tuning

After model comparison, Random Forest was selected for further tuning based on the recorded CV Mean R² results.

`RandomizedSearchCV` was used to explore parameters such as:

* `n_estimators`
* `max_depth`
* `min_samples_split`
* `min_samples_leaf`
* `max_features`

This helped systematically search for a stronger model configuration.

---

# 💾 Model Serialization

The complete Machine Learning pipeline was saved using Joblib:

```text
car_price_prediction_model.pkl
```

Saving the complete pipeline ensures that preprocessing and prediction can be reused together.
